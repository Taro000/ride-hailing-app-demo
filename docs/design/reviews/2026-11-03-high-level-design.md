## 要約

指摘は 20 件（重大 0、中 6、軽微 14）。宛先は `architecture-to-high-level-design` が 18 件、`architecture-drivers-to-architecture` が 2 件（FND-44、FND-49）。品質チェーンへの課題は 1 件（NFR-25 の数え方）。

数の上では、この段はよく閉じている。遅延の予算はスクリプトで計算し直してすべて合い（和、区間ごとのパーセンタイル、余り）、操作 70 件は仕様書、IFC、報告書の表で欠けも余りもない。報告書のエラーの表 162 行は IFC の errors と文まで一致し、29 件の実体はどれも持ち主が一つで、受け入れ基準 200 件に通らないものはなく、15 件の CUJ と 16 件の主な要求にはどれも流れか表がある。

崩れているのは、この段がいちばん手をかけた所、つまり Stripe の結果が分からないときの扱いと、その結果を乗客に示す所。中の 6 件のうち 4 件はそこで項目どうしがかみ合っておらず、残る 2 件は乗客に見えるものと記録の欠け:

- FND-30: 押さえに Stripe が 429 を返したとき（または届かなかったとき）、IFC-02 は乗客に「押さえていない、少し後に同じキーで送れる」と返すが、IFC-13 とお金の操作の図は確かめ中にして、見回りが同じキーで送る。DEC-48 では同じキーは最初の結果を返すので、乗客の送り直しは手配にならず、見回りが後で押さえて探し始めうる。
- FND-31: T_hold_wait を過ぎても Stripe が答えないとき、見回りの二つの枝が重なる。一方に従うと、確かめのないまま「押さえていない」と示す（この段の約束と完了条件に反する）。もう一方に従うと終わりがなく、DEC-52 が退けた案の理由がそのまま当たる。
- FND-32: 依頼の支払いの状態遷移図に、押さえの解放、未払いの支払い、返金、押さえ直しの結果が分からない状態がない。エラーの決まりは取り消しで payment.state = checking を返すが、図の checking から released に出る道がない。図に従えば、結果の分からない操作を released（終わり）で隠す。
- FND-33: 押さえ直しを確かめている間に乗車が終わる場合がどこにもない。確定の額が決まらず、後で見つかった新しい押さえを取り消す決まりもないので、押さえが 7 日残りうる。
- FND-45: 不在の料金、キャンセル料と不在の料金の請求の失敗、未払いを乗客の画面に示す道が欠け、未払いと確かめ中の乗車では評価の画面が出ない（FR-13、27、28、31、44 の基準）。
- FND-46: FR-12 AC5 の「変更の前後の降車場所」を残す所がない。

軽微の 14 件: ドライバーの API と管理の返金に、状態が許さないときの符号がない（FND-34）。NFR-24 と NFR-25 の出どころが対象と欄を欠く（FND-35）。実機で SLI-02 を測る関門が項目にない（FND-36）。一つ目の規則が業務の 429 を数え、参加者でない人に鳴らされうる（FND-37）。5xx の後の見回りの同じキーの送り直しは進まない（FND-38）。持ち主の例外の一覧がない（FND-39）。配信とログの仕様書が IFC と合わない（FND-40、41）。エラーに添える値を Problem で運べず、ログインのない操作に Origin の 403 がない（FND-42）。共通の約束事からの小さなずれ（FND-43）。流れと画面に描いていない知らせと表示（FND-47）。トレースの表と functions のずれ（FND-48）。第 2 段階へは、URL を公開すると 5 回の失敗で参加者のアカウントを止められること（FND-44）と、ELM-02 に FR-47 がないこと（FND-49）。

おもなリスクは、お金の結果が分からないときの状態が、流れ、エラーの決まり、二つの状態遷移図、DEC-48 と DEC-52、画面の項目の間で一つに決まっていないこと。第 4 段階はこれを ELM-01、02、04、05 で別々に作るので、ここで閉じないと乗客の画面とサーバーが違う状態を持つ。項目に書かれた引き換えは、Stripe の 2.5 秒（NFR-24 から決めた値で、NFR-44 で測る。DEC-50）、T_hold_wait の 60 秒（DEC-52）、一覧を丸ごと送ること（Turso の読み出しが 3 倍。DEC-51）で、どれも項目と要合意の表にある。

第 2 段階の未解決の指摘 FND-19〜26 と第 1 段階への FND-27 は、この段の質問 1 のとおり残ったまま。中身は出し直していない。
